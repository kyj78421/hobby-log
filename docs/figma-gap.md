## 보류·미해결
- **BL-004/성장 카드, 성장 정원**: 설계서 Overview에서 "성장 정원/캐릭터/게임화 제외"라고 명시 → 구현하지 않음.
- 인증 정책(이메일 확인·비밀번호 정책·약관): 설계서 "별도 결정" 항목. 현재 이메일 확인 ON, 비밀번호 8자 이상. 약관 미구현.
- 세션 만료 시 미저장 원고 복구: 설계서 "개발 전 결정" 항목, 미구현.
- "사진 업로드 실패 시 [사진 없이 저장]" 선택지: 현재는 실패 시 저장하지 않고 재시도만 제공 (사용자 명시 선택 없이 저장하지 않는 원칙은 충족).
