# HOBBY LOG — 정보 구조 (IA) / 사이트맵

> 표기 규칙: FigJam에서 **P1**로 표시된 항목만 P1로 분류. 표기가 없는 항목은 P0로 분류(PRD 4.2 기능 목록 기준).

---

## 1. 구조 요약

FigJam 최상위 노드 `HOBBY LOG`에서 3개 영역으로 분기한다.

| 영역 | 포함 페이지 |
| --- | --- |
| 1. 공개 영역 | 랜딩 페이지 |
| 2. 인증 영역 | 로그인, 회원가입 |
| 3. 회원 전용 영역 | 홈 대시보드, 캘린더, 아카이브, 기록 관리, 취미 설정, 마이페이지 |

> 참고: FigJam에서 `2. 인증 영역`과 `3. 회원 전용 영역`의 연결선이 하나의 선으로 합쳐져 8개 페이지로 분기한다. 위 영역별 배치는 영역 이름과 PRD 6장 기준의 분류다.

## 3. 영역별 페이지 명세

### 3.1 공개 영역

| 페이지 | URL | 우선순위 | 하위 화면 구성 |
| --- | --- | --- | --- |
| 랜딩 페이지 | `/` | P0 | 서비스 소개 · 핵심 기능 안내 · 로그인 / 회원가입 CTA |

### 3.2 인증 영역

| 페이지 | URL | 우선순위 | 하위 화면 구성 |
| --- | --- | --- | --- |
| 로그인 | `/login` | P0 | FigJam에 하위 항목 없음 |
| 회원가입 | `/signup` | P0 | FigJam에 하위 항목 없음 |

### 3.3 회원 전용 영역

| 페이지 | URL | 우선순위 | 하위 화면 구성 |
| --- | --- | --- | --- |
| 홈 대시보드 | `/` | P0 | 전체 기록 횟수 · 최근 활동 기록 · 기록 작성 바로가기 |
| ㄴ 확장 | `/` | P1 | 월간 활동 횟수 · 캘린더 미리보기 |
| 캘린더 | `/calendar` | P1 | 월간 캘린더 · 이전 달 / 다음 달 · 날짜별 활동 표시 · 선택 날짜의 기록 목록 |
| 아카이브 | `/activities` | P0 | 전체 활동 목록 · 카테고리 필터 · 날짜 정렬 · 기록 카드 |
| 기록 관리 (그룹) | URL 없음 | P0 | 기록 작성 · 기록 상세 · 기록 수정 |
| ㄴ 기록 작성 | `/activities/new` | P0 | FigJam에 하위 항목 없음 |
| ㄴ 기록 상세 | `/activities/[id]` | P0 | FigJam에 하위 항목 없음 |
| ㄴ 기록 수정 | `/activities/[id]/edit` | P0 | FigJam에 하위 항목 없음 |
| 취미 설정 | `/onboarding` | P1 | 대분류 선택 · 세부 취미 선택 · 선택 완료 / 건너뛰기 |
| 마이페이지 | `/mypage` | P0 | 계정 정보 · 누적 기록 수 · 로그아웃 |
| ㄴ 확장 | `/mypage` | P1 | 관심 취미 / 변경 |

> `/`는 FigJam에서 `랜딩 페이지`(공개)와 `홈 대시보드`(회원 전용) 두 노드에 모두 표기됨. PRD 6장: "서비스 소개 / 로그인 시 대시보드".
> `기록 관리`는 URL이 없는 묶음 노드이며, 하위 3개 화면이 각각 URL을 가짐.

## 4. 화면 간 이동 관계

FigJam 원본에 그려진 연결선은 **계층(부모 → 자식) 관계뿐**이며, 페이지 간 이동(화면 → 화면) 화살표는 없다.

- `HOBBY LOG` → 공개 영역 · 인증 영역 · 회원 전용 영역
- 공개 영역 → 랜딩 페이지
- 인증 영역 / 회원 전용 영역 → 로그인 · 회원가입 · 홈 대시보드 · 캘린더 · 아카이브 · 기록 관리 · 취미 설정 · 마이페이지
- 각 페이지 → 해당 페이지의 하위 화면 구성 항목
- 기록 관리 → 기록 작성 · 기록 상세 · 기록 수정

확인되지 않은 화면 간 이동은 추가하지 않았다.

## 5. PRD 6장 IA 표와의 대조

`prd.md` 6장의 10개 페이지가 FigJam과 모두 일치한다.

| PRD 페이지 | PRD URL | FigJam 위치 |
| --- | --- | --- |
| 랜딩·홈 | `/` | 랜딩 페이지 (공개) / 홈 대시보드 (회원 전용) |
| 로그인 | `/login` | 인증 영역 |
| 회원가입 | `/signup` | 인증 영역 |
| 취미 설정 | `/onboarding` | 회원 전용 영역 · P1 |
| 캘린더 | `/calendar` | 회원 전용 영역 · P1 |
| 아카이브 | `/activities` | 회원 전용 영역 |
| 기록 작성 | `/activities/new` | 기록 관리 |
| 기록 상세 | `/activities/[id]` | 기록 관리 |
| 기록 수정 | `/activities/[id]/edit` | 기록 관리 |
| 마이페이지 | `/mypage` | 회원 전용 영역 |

**PRD 6장 화면 원칙** (`prd.md` 원문)

- 공통 헤더·내비게이션
- 반응형 레이아웃
- 카드형 기록 UI
- 사진·이모지 중심 시각화
- 저장·수정·삭제 피드백 명확화
- 빈 화면·로딩·오류 상태 처리
- UI는 전부 한국어
