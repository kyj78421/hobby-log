## 1. 개요

### 1.1 서비스 소개

- **서비스**: 취미 활동을 캘린더와 사진 일기로 기록하는 개인 아카이빙 웹서비스
- **기록 항목**: 날짜, 사진, 감정 이모지, 만족도, 활동 내용
- **조회 방식**: 캘린더와 카드형 아카이브
- **대상**: 특정 취미가 아닌 일반 사용자

### 1.2 해결하려는 문제

| 문제 | 해결 방향 |
| --- | --- |
| 기록이 사진첩, SNS, 메모장에 분산됨 | 한곳에서 통합 관리 |
| 어떤 취미를 언제 했는지 기억이 안 남 | 날짜 기반 캘린더 |
| 사진만으론 당시 감정이 안 떠오름 | 사진 + 감정 + 내용 결합 |
| 취미별 이력 확인이 어려움 | 카테고리별 아카이브 |
| 지속할 동기가 부족함 | 누적 기록과 활동 요약 |

### 1.3 핵심 가치

- **간편한 기록**: 복잡한 설정 없이 빠르게 작성
- **감정 시각화**: 이모지와 사진으로 경험 표현
- **시간 기반 회고**: 캘린더로 취미 생활 돌아보기
- **개인 아카이빙**: 다양한 기록을 체계적으로 축적
- **범용성**: 특정 취미에 한정되지 않음

### 1.4 제품 목표

- [ ] 안전한 회원가입·로그인
- [ ] 관심 취미 선택·관리
- [ ] 날짜·사진·감정·내용 기록 작성
- [ ] 기록 조회·수정·삭제
- [ ] 월간 캘린더로 날짜별 확인
- [ ] 카테고리별 분류·탐색
- [ ] 사용자별 데이터 분리
- [ ] 모바일·PC 지원

- **P2**: 제출 이후 (통계, 검색 등)

### 4.3 상세 요구사항

#### ① 회원가입·로그인 (P0)

- **기능**: 이메일·비밀번호 가입, 로그인·로그아웃, 입력값 검증, 로그인 유지
- **접근 제어**: 비회원은 소개 화면만, 기록 CRUD는 로그인 후
- **권한**: 다른 사용자의 기록 접근 불가
- **오류**: 인증 실패 시 한국어 메시지

#### ② 취미 카테고리 (P0)

| 대분류 | 세부 취미 예시 |
| --- | --- |
| 스포츠·운동 | 러닝, 헬스, 수영, 요가, 구기 |
| 문화·예술 | 영화, 공연, 전시, 음악 감상 |
| 창작·공예 | 그림, 사진, 뜨개질, 도예, DIY |
| 학습·자기계발 | 독서, 외국어, 프로그래밍, 글쓰기 |
| 여행·아웃도어 | 여행, 등산, 캠핑, 낚시 |
| 요리·미식 | 요리, 베이킹, 커피, 미식 탐방 |
| 게임·엔터테인먼트 | 비디오 게임, 보드게임, 퍼즐 |
| 생활·수집 | 원예, 수집, 반려동물 활동 |
| 기타 | 위 분류에 없는 활동 |

- **구조**: 대분류와 세부 취미를 구분
- **초기 버전**: 사전 정의된 분류만 제공
- **운영**: 운영자가 추후 추가·변경·통합 가능
- **데이터**: 카테고리명을 바꿔도 기존 기록 유지
- **제외**: 사용자 직접 생성은 후속 개발

#### ③ 기록 작성 (P0)

| 입력 항목 | 방식 | 필수 |
| --- | --- | --- |
| 활동 날짜 | 날짜 선택 | ✅ |
| 취미 카테고리 | 선택 | ✅ |
| 세부 취미 | 선택 | ✅ |
| 기록 제목 | 텍스트 | ✅ |
| 활동 내용 | 자유 입력 | ✅ |
| 감정 | 이모지 선택 | 선택 |
| 만족도 | 1~5점 | 선택 |
| 활동 사진 | 이미지 첨부 | 선택 |

- **검증**: 필수값 누락 시 저장하지 않고 안내
- **저장 후**: 상세 화면 또는 목록에서 확인
- **실패 시**: 작성 중인 내용 유지
- **중복 방지**: 중복 저장 차단
- **원칙**: 선택 항목 없이도 최소 기록 가능

#### ④ 개인 아카이브 (P0)

- **기능**: 카드 목록, 날짜순 정렬, 카테고리 필터, 상세, 수정, 삭제
- **카드 정보**: 썸네일, 제목, 날짜, 카테고리, 감정, 만족도
- **기본 정렬**: 최근 활동순
- **빈 상태**: 기록이 없으면 작성 안내, 필터 결과가 없으면 안내 메시지
- **삭제**: 삭제 전 확인 절차

#### ⑤ 메인 대시보드 (P0/P1)

- **P0**: 헤더·내비게이션, 전체 기록 수, 최근 기록, 기록 작성 버튼
- **P1**: 월간 캘린더, 이번 달 활동 횟수, 날짜별 감정 표시

#### ⑥ 마이페이지 (P0)

- **기능**: 계정 정보, 전체 기록 횟수, 관심 취미 표시, 로그아웃
- **P1**: 관심 취미 변경

#### ⑦ DB 연동 (P0)

- 회원별 기록을 DB에 저장
- 로그인한 사용자만 본인 기록 조회·수정·삭제
- 저장·수정·삭제 결과를 화면에 즉시 반영
- 요청 실패 시 오류 메시지 표시
- 새로고침·재로그인 후에도 유지
- 테이블 구조와 SQL은 별도 기술 설계 문서에서 다룸

#### ⑧ 관심 취미 선택 (P1)

- **기능**: 가입 후 복수 선택, 마이페이지 확인, 변경
- **UX**: 건너뛰기 가능, 관심 취미 외 활동도 기록 가능
- **일관성**: 관심 취미와 기록 분류를 동일하게 유지

#### ⑨ 감정 이모지 (P1)

| 이모지 | 감정 |
| --- | --- |
| 😆 | 신남 |
| 🥰 | 행복 |
| 😌 | 평온 |
| 😎 | 뿌듯 |
| 😐 | 보통 |
| 😴 | 피곤 |
| 😢 | 슬픔 |
| 😤 | 답답함 |

- 기록당 대표 감정 1개, 선택 취소 가능
- 상세 화면과 캘린더에 표시
- 감정 종류는 운영 후 변경 가능

#### ⑩ 만족도 (P1)

- **입력**: 1~5점 별점, 선택, 클릭·탭으로 입력
- **수정**: 기록 수정 시 변경 가능
- **원칙**: 감정과 별도 관리 (힘든 운동도 만족도는 높을 수 있음)

#### ⑪ 사진 첨부 (P1)

- **기능**: 기록당 1장, 미리보기, 변경·삭제, 상세 표시
- **제약**: JPG·PNG·WebP, 5MB 이하
- **오류**: 형식·크기·저장 실패 시 안내
- **권한**: 사용자별 업로드·조회 권한 검증
- **저장소**: Supabase Storage

#### ⑫ 취미 캘린더 (P1)

- **기능**: 월간 보기, 월 이동, 활동일 표시, 감정 표시, 오늘 강조
- **날짜 선택**: 해당 날짜 기록 조회, 같은 날 여러 기록 가능
- **빈 상태**: 기록 없는 날짜는 빈 상태 표시
- **갱신**: 작성·수정·삭제 후 즉시 반영
- **모바일**: 날짜 선택 가능해야 함

## 8. 제한사항 및 비기능 요구사항

### 8.1 서비스 제한

- 한국어 기본 제공
- 기록은 기본 비공개
- 사진은 기록당 1장
- 공개 피드·소셜 기능 없음
- 직접 그리기 기능 없음
- 커스텀 카테고리는 초기 범위 제외

### 8.2 보안·개인정보

- 사용자별 접근 권한 검증
- 비인증 요청 차단
- 사진 권한을 기록 권한과 일치
- 가입·개인정보 관련 안내 제공
- 일반 공개 전 개인정보 처리방침, 기록 삭제, 계정 탈퇴 절차 점검

### 8.3 품질

- 모바일·데스크톱 정상 표시
- 주요 버튼·입력 정상 작동
- 저장 실패·인증 실패·빈 상태 메시지 제공
- 직접 접근·새로고침에도 정상 동작
- 치명적인 콘솔 오류 없음
